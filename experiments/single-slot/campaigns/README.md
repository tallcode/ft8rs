# Single slot receiver campaigns

- [First campaign](01-single-slot-research/README.md): complete original research archive, frozen versions, self-checks, checkpoints and its own aggregate analyses.
- [Second campaign](02-hybrid-specialist/README.md): Hybrid-only implementation, frozen binary/source, raw confirmation runs, development/final analyses and completion audit.

Each campaign owns its own results. The former shared result directory was removed after lossless partitioning and duplicate verification. No raw audio, original run or first-campaign archive was deleted.

## Versioned test evidence

Raw text results, diagnostics, frozen source snapshots, generators, seeds,
configuration, hashes and compact analyses are included in Git. First-campaign
raw records have been expanded from the complete local archive so they are also
protected by a source push. Generated WAVs, compiled binaries and compressed
local archives remain ignored and locally preserved.

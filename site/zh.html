这是什么

ft8.rs 是一款 FT8 解码软件。将电台或 SDR 的接收音频送入电脑，就可以查看收到的呼号、信号强度和消息。

它只接收，不带发射功能。你可以用它收听频段活动，也可以针对一个呼号持续监听。软件提供 WSJT-X、JTDX、Hybrid 和 DX 四种解码模式。

开始使用

以下步骤适用于 Windows 图形界面。

  1. 连接音频。将电台或 SDR 调到要收听的 FT8 频率，通过声卡、USB 音频或虚拟音频线把接收音频送入电脑。保持电脑系统时间准确。
  2. 打开软件。完整解压下载的 ZIP 文件，运行 ft8rs-gui.exe。
  3. 选择输入。在 Settings → Audio 中选择接收机对应的输入设备和声道，确认有音频电平。如果只有一侧声道有信号，就选择对应的 Left 或 Right。
  4. 选择模式。初次使用可以保留默认的 WSJT-X。在 Settings → Decode 中可以切换其他模式。
  5. 开始收听。点击主窗口的播放按钮。软件按 15 秒一轮接收 FT8，完成一轮接收后会陆续显示消息；点击停止按钮结束收听。

一般收听不必填写自己的呼号。需要时可在 Settings → Station 填写呼号和网格位置。

怎样选择解码模式

WSJT-X
默认模式，适合开始收听。
JTDX
使用 JTDX 解码方式，可尝试与默认模式对照。
Hybrid
组合 WSJT-X 和 JTDX 的解码结果，会使用更多计算资源。
DX
关注一个目标呼号。先在主窗口的 Callsign 中填入目标呼号，再开始收听。双击已解码的消息也可以选中目标。

没有收到消息？

先检查接收频率、电脑时间和音频输入。在 Settings → Audio 查看电平，确认选中的是接收机音频，且输入没有过载。如果电平一直没有变化，请检查设备、声道和系统的音频输入权限。

Linux 命令行

在解压目录打开终端，先列出输入设备，再用对应的设备编号开始收听：

./ft8rs monitor
./ft8rs monitor --device 0

命令行也支持解码 WAV 录音。更多音频设置、录音解码和 UDP 使用方法见 完整使用说明（英文）。
